# TCEG 抽取过程与方法 · B 模板

这是一套 12 页、16:9 的 HTML 演示文稿，用于说明如何把券商研报转化为可审计的 TCEG 语义状态。内容来自江波龙研报的真实抽取结果，不含示意占位数据。

## 打开方式

- 动态入口：`http://127.0.0.1:8765/method-deck/`
- 本地入口：`index.html`
- PDF：`output/TCEG抽取过程与方法_B模板_12页.pdf`

动态入口依赖项目可视化服务：

```bash
python3 tools/serve_tceg_visualization.py --host 127.0.0.1 --port 8765
```

入口默认显示 12 页总览墙。点击“开始演示”或任意页面进入演示；方向键、空格键翻页，`Esc` 返回总览，`P` 打印或另存为 PDF。

## 页面结构

1. 核心命题与样本
2. 图作为唯一语义状态的契约
3. Schema：根状态、文档与来源对象字段
4. Schema：节点、证据、数值与复核字段
5. Schema：关系类型、运行审计与覆盖字段
6. 六阶段抽取流程
7. 不可漂移的原始证据层
8. 大模型与确定性解析的分工
9. 本体与数字语义
10. 原文证据门
11. 关系验证与论证 DAG
12. 最终图与验证结果
