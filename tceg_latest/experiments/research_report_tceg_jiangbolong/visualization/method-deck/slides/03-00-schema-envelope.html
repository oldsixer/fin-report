TCEG METHOD

Schema 01 · State & Provenance

Canonical state envelope

一个 TCEG 文件同时保存语义状态、来源身份和抽取审计。

ROOT + DOCUMENT

回答“这是谁的图、来自哪份文件”。

schema_version · graph_id
结构契约版本；这份图的稳定身份。
state_hash
document、source、node、edge 规范状态的内容指纹。
source_objects · nodes · edges
证据对象、语义对象和有向关系三类主集合。
extraction_run · coverage_manifest
运行审计与覆盖统计；不参与语义状态哈希。
rejected_candidates
保存被拒候选，不让失败样本从审计链消失。
document.id · title · source_type
文档身份、标题与载体类型。
local_path · source_url · sha256
本地文件、外部入口及原文件完整性。
publisher · published_at · issuer
发布机构、日期和研究标的。

SOURCE OBJECT

回答“这条语义究竟引用了哪段原文”。

id · document_id · sequence
稳定来源 ID、所属文档及阅读顺序。
object_type
paragraph / table_like / figure_caption / legal / other。
raw_text · normalized_text
保留原始文本；另存证据匹配用规范文本。
sha256
raw_text 的内容哈希，检测来源漂移。
locator.page · block
定位到 PDF 页与页内块。
locator.char_start · char_end
可用时记录页内字符边界。
processing_status
EXTRACTED / NO_CLAIM / OPAQUE / NEEDS_REVIEW / ERROR。
candidate_count · irrelevant_reason
候选数量；无有效语义时保留原因。
metadata.extraction_method
记录该来源对象由何种解析器生成。

根字段定义来自 research-report-tceg-0.1 与当前真实图状态。

STATE = SEMANTICS + PROVENANCE + AUDIT
