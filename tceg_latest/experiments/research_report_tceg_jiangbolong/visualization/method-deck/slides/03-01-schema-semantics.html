TCEG METHOD

Schema 02 · Nodes & Embedded Records

Semantic node dictionary

节点描述“是什么”；证据和值对象让它保持可核验、可计算。

NODE RECORD

所有节点共享身份字段，再由 node_type 补充语义。

id · node_type · label · status
稳定身份、类型、可读名称及 active / needs_review / rejected 状态。
Entity.entity_type
公司、产品、人物等实体类别。
Metric.canonical_name
跨表格复用的规范指标名。
Period.normalized_label
统一后的年度、季度或时点表达。
Claim
claim_role / modality / polarity / importance；subject_ref / predicate / object_text / metric_ref / period_ref；assertion_level / evidence。
DataPoint
subject_ref / metric_ref / period_ref / qualifier；value / extraction_method / assertion_level / evidence。
Event
category / subject_ref / period_ref / assertion_level / evidence。
ReasoningStep
reasoning_method / premise_node_ids / conclusion_claim_ids / rationale / assertion_level / verification。
Assumption
Schema 预留的假设节点；当前样本为 0，至少使用公共身份字段。

EMBEDDED RECORDS

这些字段是受约束的结构，不是随意附加的备注。

evidence.source_object_id
被引用的不可漂移来源对象。
evidence.quote · quote_sha256
连续原文及其内容指纹。
evidence.match_mode
exact 或 whitespace_normalized。
value.kind · raw
scalar / range / text；同时保留报告中的原始字形。
value.normalized_decimal
标量的精确十进制规范值。
value.range_low · range_high
范围型数字的下界与上界。
value.unit · currency · scale
单位、币种和倍率；三者共同还原真实量级。
value.dimensions
产品、地区、业务口径等附加维度。
verification.verdict · confidence
独立模型的 accept / reject 判断与 0–1 置信度。
verification.reason · model
复核理由以及实际验证模型。

引用字段全部指向稳定 ID；DataPoint 缺少主体、指标或期间即验证失败。
