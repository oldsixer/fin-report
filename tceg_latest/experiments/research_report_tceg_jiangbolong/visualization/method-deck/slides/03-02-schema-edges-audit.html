EDGE RECORD + TYPES

每条边都有方向、断言级别、置信度与生命周期。

id · edge_type · source_id · target_id

rationale · evidence
论证理由及显式关系的原文依据。

within/cross chunk 来源及独立复核记录。

EVIDENCED_BY

ABOUT · MEASURES · VALID_DURING

HAS_DATA

SUPPORTS · CONTRADICTS

PREMISE_OF · CONCLUDES

EXTRACTION RUN + COVERAGE

运行诊断不改变语义哈希，但必须保留以便复现。

RUN · run_id / started_from / finished_at / model / verification_model / extractor / candidate_input / semantic_contract
运行身份、时间、模型、管线版本、输入位置与语义约束。
CHUNK · chunk_count / resumed_candidate_chunks / deterministic_table_points_created / deterministic_capacity_points_created
分块、断点恢复与两类确定性 DataPoint 产量。
API CALL · api_calls[].id / purpose / model / stage / status / attempt / duration_seconds / finish_reason
逐次模型调用的目标、阶段、状态、重试、耗时与完成原因。
CALL INTEGRITY · prompt_sha256 / response_sha256 / json_repair_applied / usage.{prompt_tokens, completion_tokens, total_tokens}
输入输出指纹、JSON 修复标志和 token 用量。
COVERAGE · total_source_objects / terminal_source_objects / source_object_status_counts / source_processing_coverage
来源处理总量、终态、状态分布与处理覆盖率。
EVIDENCE COVERAGE · semantic_nodes / semantic_nodes_with_evidence / semantic_evidence_coverage
语义节点及其证据覆盖口径。
REVIEW · opaque_source_object_ids / needs_review_source_object_ids / definition
不透明对象、复核队列与统计口径定义。
REJECTED · rejected_candidates[].{id, candidate_type, chunk_id, reason, candidate}
保留被拒候选及其原始内容和失败原因。
